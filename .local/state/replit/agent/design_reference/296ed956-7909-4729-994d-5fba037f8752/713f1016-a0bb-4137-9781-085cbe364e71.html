API Endpoints

POST /api/parse-excel
Connected to UploadPanel

Accepts uploaded Excel files and extracts table metadata, column definitions, and foreign key relationships.

Request

Content-Type: multipart/form-data

file: Excel file (.xlsx)
Max size: 5MB
Required sheets:
- TableMetadata
- AttributeMetadata

Response

{
  "tables": [
    {
      "name": "User",
      "attributes": [
        {
          "name": "Id",
          "type": "int",
          "is_pk": true
        }
      ]
    }
  ],
  "relationships": [...]
}

Test This Endpoint

Upload a sample Excel file to test the parsing functionality

POST /api/generate-mermaid
Connected to ERDRenderer

Converts parsed table metadata into valid Mermaid ERD syntax for diagram rendering.

Request

{
  "tables": [...],
  "relationships": [...],
  "options": {
    "theme": "default",
    "direction": "TB"
  }
}

Response

{
  "diagram": "erDiagram\n  User {...}\n  Order {...}",
  "metadata": {
    "tables_count": 3,
    "relationships_count": 2
  }
}
